# My First Mobile App 

## Description
I'm following the "Learn JavaScript" course on [Scrimba](https://scrimba.com/home) and this is the fourth (and last) part of it.
In the previous part, I built a Chrome extension. In this part, I will learn how to connect it to a real-time database using [Firebase](https://firebase.google.com/). 
Then using [Web Application Manifest](https://developer.mozilla.org/en-US/docs/Web/Manifest) I turned the web app into a "mobile" app.

## Features
This "mobile" app allows users to save URLs by passing them into an input field.
The URLs are then displayed inside the "mobile" app and saved inside my real-time Firebase database.

## "Mobile" app version
If you would like to use my Leads Tracker as a "mobile" app as well, you can follow these steps:

### Android
1. Open up the default browser of the system: Google Chrome.
2. Go to the Leads Tracker web app by pasting in the exact URL: https://robinsrepository.github.io/first-mobile-app/
3. Tap the button on the top right with the three dots.
4. Tap 'Add to Home screen'.
5. You can change the name and tap 'Add'.
6. Tap 'Add to home screen' again.
7. Now you will find the "mobile" app on your home screen, enjoy using it!

### iPhone
1. Open up the default browser of the system: Safari.
2. Go to the Leads Tracker web app by pasting in the exact URL: https://robinsrepository.github.io/first-mobile-app/
3. Tap the button in the middle at the bottom looking like a square with an arrow pointing up out of it.
4. Tap 'Add to Home Screen'.
5. You can change the name and tap 'Add'.
6. Now you will find the "mobile" app on your home screen, enjoy using it!
